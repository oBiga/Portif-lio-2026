Atividade: Sistema Toggle de LED com Arduino

Habilidades desenvolvidas: Programação de microcontroladores, utilização de entradas e saídas digitais, aplicação de estruturas condicionais e controle de estados. Nesta atividade, foi desenvolvido um sistema toggle utilizando Arduino, botão e LED. Diferentemente do acionamento simples, cada pressionamento do botão alterna o estado do LED: quando está apagado, o botão faz com que ele acenda; quando está aceso, o próximo pressionamento faz com que ele apague. O projeto permitiu aplicar lógica de programação para controlar e armazenar o estado de um componente eletrônico.

Atividade: Controle de LED com Botão no Arduino

Habilidades desenvolvidas: Programação de microcontroladores, utilização de entradas e saídas digitais e desenvolvimento de circuitos eletrônicos. Nesta atividade, foi desenvolvido um circuito com Arduino, botão e LED, no qual o pressionamento do botão faz com que o LED acenda. O projeto permitiu aplicar conceitos de programação e eletrônica para estabelecer a comunicação entre uma entrada digital e uma saída do Arduino.
