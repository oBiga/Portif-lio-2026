Atividade: GATEWAY DE PAGAMENTO

Habilidades desenvolvidas: H1, H4 e H6

Objetivo: Desenvolver uma aplicação que simule um gateway de pagamento, aplicando conhecimentos de programação, APIs, frameworks, banco de dados e princípios de segurança, usabilidade e integridade das informações.

Resumo: A atividade consistiu no desenvolvimento, em equipe, de um gateway de pagamento para o Ensino Médio Técnico. O projeto simulou um sistema real de processamento de pagamentos, envolvendo cobrança de cartões, aplicação de taxas de acordo com a bandeira, cálculo de juros compostos conforme o número de parcelas e controle de um limite diário de R$ 5.000 por cartão. Como solução, foi desenvolvido um sistema com backend em Node.js, frontend em React e banco de dados SQLite, organizado em um repositório no GitHub com documentação da arquitetura.
